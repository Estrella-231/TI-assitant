# Embedded Engineering Notes

本目录是一个无需构建工具的静态博客，入口为 `index.html`。文章内容迁移自 Ti-Project-Assistant 使用教程，并保留原作者与项目链接。

## 本地预览

在 `E:\2026electronic\blog` 执行：

```powershell
python -m http.server 8000
```

浏览器打开 <http://localhost:8000>。

## 部署

将 `blog` 目录上传到 GitHub Pages、Cloudflare Pages、Vercel、Netlify 或任意静态 Web 服务器即可。
